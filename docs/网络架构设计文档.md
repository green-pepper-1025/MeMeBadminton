# 《抽象羽球大乱斗》网络架构设计文档

## 一、架构总览

### 1.1 设计目标

| 目标 | 指标 |
|------|------|
| 延迟 | 同局域网 < 20ms，跨网 < 100ms |
| 帧率 | 60fps 下物理表现流畅 |
| 同步精度 | 球位置误差 < 5px |
| 容错 | 200ms 内网络抖动不影响游戏体验 |

### 1.2 核心设计原则

1. **服务器权威**: 服务器是唯一的物理计算和得分判定者
2. **客户端预测**: 客户端立即响应输入，不等待服务器确认
3. **状态校正**: 客户端接收服务器状态后平滑校正偏差
4. **事件同步**: 关键事件（击球、得分）必须同步；位置通过插值平滑

### 1.3 整体通信架构

```
┌─────────────────────┐          ┌─────────────────────┐
│      客户端 A        │          │      客户端 B        │
│                     │          │                     │
│  Input → Predict    │          │  Input → Predict    │
│  NetworkManager     │          │  NetworkManager     │
│  MessageHandler     │          │  MessageHandler     │
└─────────┬───────────┘          └──────────┬──────────┘
          │ WebSocket                        │ WebSocket
          │                                  │
          └──────────────┬───────────────────┘
                         │
              ┌──────────▼──────────┐
              │    Go WebSocket      │
              │       Server         │
              │                     │
              │  Room Manager       │
              │  Game Logic         │
              │  Physics Engine     │
              │  Score System       │
              └─────────────────────┘
```

## 三、同步策略

### 3.1 输入-预测-校正模型

这是解决网络延迟感知问题的核心机制。

```
时间轴（客户端A视角）：

T+0ms   玩家按下 S 键（挥拍）
         ┌→ 客户端立即播放挥拍动画（预测）
         └→ 发送 PLAYER_INPUT{hit:true, seq:42} 给服务器

T+50ms  服务器接收到输入
         ┌→ 服务器计算碰撞结果
         └→ 广播 BALL_SYNC{...} 给所有客户端

T+100ms 客户端A接收到服务器的球状态
         ┌→ 比较服务器状态与本地预测状态
         └→ 差异 < 阈值：忽略（保持本地状态）
            差异 ≥ 阈值：平滑插值到服务器状态
```

### 3.2 状态校正算法

```typescript
class SyncManager {
    private readonly SNAP_THRESHOLD = 100;     // 超过100px直接跳变
    private readonly LERP_THRESHOLD = 20;      // 小于20px忽略偏差
    private readonly LERP_SPEED = 0.3;         // 插值速度（每帧）
    
    /**
     * 校正球的位置
     */
    correctBallState(
        localState: BallState, 
        serverState: BallSyncData
    ): BallState {
        const dx = serverState.x - localState.x;
        const dy = serverState.y - localState.y;
        const dist = Math.sqrt(dx * dx + dy * dy);
        
        if (dist > this.SNAP_THRESHOLD) {
            // 偏差过大，直接跳变
            return {
                x: serverState.x,
                y: serverState.y,
                vx: serverState.vx,
                vy: serverState.vy
            };
        } else if (dist < this.LERP_THRESHOLD) {
            // 偏差很小，忽略
            return localState;
        } else {
            // 平滑插值
            return {
                x: localState.x + dx * this.LERP_SPEED,
                y: localState.y + dy * this.LERP_SPEED,
                vx: serverState.vx,
                vy: serverState.vy
            };
        }
    }
}
```

### 3.4 延迟补偿

对于技能和击球等关键事件，使用时间戳进行延迟补偿：

```typescript
interface TimestampedEvent {
    type: string;
    timestamp: number;      // 客户端发送时间
    serverTime: number;     // 服务器接收时间
    latency: number;        // 计算得到的延迟
}

class LatencyCompensation {
    private _avgLatency: number = 0;
    
    /**
     * 更新延迟估计（基于心跳响应）
     */
    updateLatency(sendTime: number, receiveTime: number): void {
        const rtt = receiveTime - sendTime;
        // 使用指数移动平均平滑延迟估计
        this._avgLatency = this._avgLatency * 0.8 + (rtt / 2) * 0.2;
    }
    
    /**
     * 获取当前延迟估计（单向）
     */
    getLatency(): number {
        return this._avgLatency;
    }
}
```

## 四、客户端网络模块实现

### 4.1 NetworkManager

```typescript
/**
 * 网络管理器
 * 职责：管理 WebSocket 连接，发送消息，分发接收到的消息
 */
export class NetworkManager {
    private static _instance: NetworkManager;
    private _ws: WebSocket | null = null;
    private _connected: boolean = false;
    private _reconnectAttempts: number = 0;
    private _maxReconnectAttempts: number = 5;
    private _reconnectDelay: number = 2000;
    private _msgIdCounter: number = 0;
    
    // 心跳
    private _heartbeatInterval: number = 1000;  // 1秒
    private _heartbeatTimer: number | null = null;
    private _lastHeartbeatTime: number = 0;
    
    public static getInstance(): NetworkManager {
        if (!NetworkManager._instance) {
            NetworkManager._instance = new NetworkManager();
        }
        return NetworkManager._instance;
    }
    
    /**
     * 连接服务器
     */
    public connect(url: string): void {
        Logger.info(`Connecting to ${url}`, 'NetworkManager');
        
        this._ws = new WebSocket(url);
        this._ws.onopen = this._onOpen.bind(this);
        this._ws.onclose = this._onClose.bind(this);
        this._ws.onerror = this._onError.bind(this);
        this._ws.onmessage = this._onMessage.bind(this);
    }
    
    /**
     * 发送消息
     */
    public send(type: MessageType, data: object): void {
        if (!this._connected || !this._ws) {
            Logger.warn('Cannot send: not connected', 'NetworkManager');
            return;
        }
        
        const message: NetworkMessage = {
            msgId: ++this._msgIdCounter,
            type,
            timestamp: Date.now(),
            data
        };
        
        this._ws.send(JSON.stringify(message));
    }
    
    // ── 内部处理 ─────────────────────────────────────────
    
    private _onOpen(): void {
        this._connected = true;
        this._reconnectAttempts = 0;
        Logger.info('WebSocket connected', 'NetworkManager');
        
        // 启动心跳
        this._startHeartbeat();
        
        EventBus.emit(GameEvent.NETWORK_CONNECTED);
    }
    
    private _onClose(event: CloseEvent): void {
        this._connected = false;
        this._stopHeartbeat();
        Logger.warn(`WebSocket closed: ${event.code} ${event.reason}`, 'NetworkManager');
        
        EventBus.emit(GameEvent.NETWORK_DISCONNECTED);
        
        // 自动重连
        this._scheduleReconnect();
    }
    
    private _onError(error: Event): void {
        Logger.error('WebSocket error', 'NetworkManager');
    }
    
    private _onMessage(event: MessageEvent): void {
        try {
            const message: NetworkMessage = JSON.parse(event.data);
            MessageHandler.getInstance().dispatch(message);
        } catch (e) {
            Logger.error('Failed to parse message', 'NetworkManager', e as Error);
        }
    }
    
    // ── 心跳机制 ─────────────────────────────────────────
    
    private _startHeartbeat(): void {
        this._heartbeatTimer = setInterval(() => {
            this._lastHeartbeatTime = Date.now();
            this.send(MessageType.HEARTBEAT, { time: this._lastHeartbeatTime });
        }, this._heartbeatInterval) as unknown as number;
    }
    
    private _stopHeartbeat(): void {
        if (this._heartbeatTimer !== null) {
            clearInterval(this._heartbeatTimer);
            this._heartbeatTimer = null;
        }
    }
    
    // ── 断线重连 ─────────────────────────────────────────
    
    private _scheduleReconnect(): void {
        if (this._reconnectAttempts >= this._maxReconnectAttempts) {
            Logger.error('Max reconnect attempts reached', 'NetworkManager');
            EventBus.emit('network:reconnect_failed');
            return;
        }
        
        this._reconnectAttempts++;
        const delay = this._reconnectDelay * this._reconnectAttempts;
        
        Logger.info(
            `Reconnect attempt ${this._reconnectAttempts} in ${delay}ms`, 
            'NetworkManager'
        );
        
        setTimeout(() => {
            if (!this._connected) {
                this.connect(this._serverUrl);
            }
        }, delay);
    }
    
    private _serverUrl: string = '';
}
```

### 4.2 MessageHandler

```typescript
/**
 * 消息处理器
 * 职责：分发接收到的网络消息到对应的处理函数
 */
export class MessageHandler {
    private static _instance: MessageHandler;
    
    private _handlers: Map<MessageType, (data: any) => void> = new Map();
    
    public static getInstance(): MessageHandler {
        if (!MessageHandler._instance) {
            MessageHandler._instance = new MessageHandler();
        }
        return MessageHandler._instance;
    }
    
    /**
     * 注册消息处理函数
     */
    public register(type: MessageType, handler: (data: any) => void): void {
        this._handlers.set(type, handler);
    }
    
    /**
     * 分发消息
     */
    public dispatch(message: NetworkMessage): void {
        const handler = this._handlers.get(message.type);
        
        if (handler) {
            handler(message.data);
        } else {
            Logger.warn(`No handler for message type: ${message.type}`, 'MessageHandler');
        }
    }
    
    /**
     * 初始化所有消息处理器（在游戏初始化时调用）
     */
    public initHandlers(): void {
        // 心跳
        this.register(MessageType.HEARTBEAT_ACK, (data) => {
            const latency = Date.now() - data.time;
            LatencyCompensation.getInstance().updateLatency(data.time, Date.now());
            Logger.debug(`Latency: ${latency}ms`, 'MessageHandler');
        });
        
        // 匹配相关
        this.register(MessageType.MATCH_FOUND, (data: MatchFoundData) => {
            EventBus.emit('match:found', data);
        });
        
        this.register(MessageType.MATCH_START, (data: MatchStartData) => {
            EventBus.emit(GameEvent.MATCH_START, data);
        });
        
        // 状态同步
        this.register(MessageType.BALL_SYNC, (data: BallSyncData) => {
            SyncManager.getInstance().onBallSync(data);
        });
        
        this.register(MessageType.PLAYER_SYNC, (data: PlayerSyncData) => {
            SyncManager.getInstance().onPlayerSync(data);
        });
        
        // 技能同步
        this.register(MessageType.SKILL_SYNC, (data: SkillSyncData) => {
            EventBus.emit('skill:sync', data);
        });
        
        // 比赛事件
        this.register(MessageType.SCORE_UPDATE, (data: ScoreUpdateData) => {
            EventBus.emit(GameEvent.SCORE_CHANGED, data);
        });
        
        this.register(MessageType.ROUND_END, (data) => {
            EventBus.emit(GameEvent.ROUND_END, data);
        });
        
        this.register(MessageType.MATCH_END, (data) => {
            EventBus.emit(GameEvent.MATCH_END, data);
        });
    }
}
```

### 4.3 InputSender（输入发送器）

```typescript
/**
 * 输入发送器
 * 职责：每帧收集玩家输入并发送到服务器
 */
export class InputSender extends Component {
    private _inputSeq: number = 0;
    private _networkManager: NetworkManager;
    
    // 上一帧的输入状态（用于去重）
    private _lastInput: PlayerInputData | null = null;
    
    onLoad() {
        this._networkManager = NetworkManager.getInstance();
    }
    
    /**
     * 每帧发送输入
     * 注意：即使输入没有变化也发送（服务器需要确认玩家存活）
     */
    update(_dt: number): void {
        const input: PlayerInputData = {
            seq: ++this._inputSeq,
            moveX: this._getMoveX(),
            jump: input.keyboard('w'),
            hit: input.keyboard('s'),
            racketAngle: this._getRacketAngle()
        };
        
        this._networkManager.send(MessageType.PLAYER_INPUT, input);
    }
    
    private _getMoveX(): number {
        const left = input.keyboard('a') ? -1 : 0;
        const right = input.keyboard('d') ? 1 : 0;
        return left + right;
    }
    
    private _getRacketAngle(): number {
        // 从鼠标位置计算球拍角度
        const mousePos = input.mousePosition;
        const playerPos = this.node.getWorldPosition();
        const dx = mousePos.x - playerPos.x;
        const dy = mousePos.y - playerPos.y;
        return Math.atan2(dy, dx);
    }
}
```

### 5.3 游戏循环（服务器端 60fps）

```go
// internal/game/match.go

func (m *Match) Start() {
    ticker := time.NewTicker(time.Second / 60)  // 60 ticks/秒
    defer ticker.Stop()
    
    for {
        select {
        case <-ticker.C:
            m.tick()
        case input := <-m.inputChan:
            m.processInput(input)
        case <-m.done:
            return
        }
    }
}

func (m *Match) tick() {
    // 1. 处理待处理的输入
    m.flushInputs()
    
    // 2. 更新物理
    m.physics.Update(1.0 / 60.0)
    
    // 3. 检查碰撞
    m.checkCollisions()
    
    // 4. 检查得分
    m.checkScoring()
    
    // 5. 广播状态
    m.broadcastState()
}

func (m *Match) broadcastState() {
    ballState := m.physics.GetBallState()
    
    // 广播球状态
    m.room.Broadcast(MessageType.BALL_SYNC, BallSyncData{
        X:  ballState.X,
        Y:  ballState.Y,
        VX: ballState.VX,
        VY: ballState.VY,
        LastHitBy: m.ball.LastHitBy,
        ServerTick: m.currentTick,
    })
    
    // 广播玩家状态
    for _, player := range m.players {
        m.room.Broadcast(MessageType.PLAYER_SYNC, PlayerSyncData{
            // ...
        })
    }
    
    m.currentTick++
}
```

## 七、错误处理与容错设计

### 7.1 断线处理

```typescript
// 客户端断线处理策略
class DisconnectHandler {
    // 断线后等待重连的最大时间（毫秒）
    private readonly MAX_RECONNECT_WAIT = 10000;
    
    onDisconnect(): void {
        // 1. 暂停游戏物理更新
        GameStateManager.getInstance().changeState(GameState.DISCONNECTED);
        
        // 2. 显示重连提示
        UIManager.getInstance().showPopup(PopupType.RECONNECTING);
        
        // 3. 开始计时
        this._startDisconnectTimer();
    }
    
    onReconnect(): void {
        // 1. 请求服务器当前游戏状态
        NetworkManager.getInstance().send(
            MessageType.REQUEST_GAME_STATE, 
            {}
        );
        
        // 2. 恢复游戏
        UIManager.getInstance().closePopup();
    }
}
```

### 7.2 消息丢失处理

由于游戏采用状态同步（每帧广播完整状态），消息丢失对游戏体验影响较小：
- **物理状态**: 下一帧会收到新的完整状态，自动恢复
- **得分事件**: 服务器重连后发送当前完整比赛状态
- **技能事件**: 服务器重连后重放技能效果

### 7.3 延迟过高处理

```typescript
// 延迟检测
class LatencyMonitor {
    private readonly WARNING_LATENCY = 150;    // 150ms 显示警告
    private readonly CRITICAL_LATENCY = 300;   // 300ms 显示严重警告
    
    onLatencyUpdate(latency: number): void {
        if (latency > this.CRITICAL_LATENCY) {
            UIManager.showToast('网络状况较差', 'error');

        }
    }
}
```

## 九、总结

网络架构的核心要点：

1. **服务器权威**：物理和得分只在服务器计算，客户端只显示
2. **客户端预测**：玩家自己的输入立即响应，不等服务器
3. **状态插值**：收到服务器状态后平滑校正，避免跳变
4. **心跳机制**：实时监控连接状态和延迟
5. **断线重连**：自动重连 + 状态恢复

通过以上策略，在 100ms 网络延迟下，玩家体验依然流畅。
