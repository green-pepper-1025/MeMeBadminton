
# 《抽象羽球大乱斗》项目策划书

## 一、 项目概况
* **项目名称：** 抽象羽球大乱斗 (Abstract Badminton Showdown)
* **项目性质：** 大三专业课大作业（两人小组）
* **开发平台：** Cocos Creator (PC端)
* **核心亮点：** 互联网抽象文化（梗角色）+ 实时联机对战 + 策略技能系统

---

## 二、 游戏规则与玩法设计
### 1. 基础规则
* **计分制：** 采用 **11分制**，率先达到11分的一方获得本局胜利。
* **赛制：** **三局两胜制** (Best of Three)。
* **发球权：** 初始随机分配，随后由得分方发球。

### 2. 操作逻辑 (PC端)
| 按键 | 动作 | 说明 |
| :--- | :--- | :--- |
| **W** | 跳跃 | 向上跃起，用于接高球或扣杀。 |
| **A / D** | 左右移动 | 控制角色在半场内的横向位移。 |
| **S** | 挥拍 | 单次触发，判定范围集中在球拍碰撞体。 |
| **Space** | 释放技能 | 能量满额且有剩余次数时触发角色专属技能。 |

---

## 三、 核心系统设计
### 1. 技能与充能机制 (Hybrid Charge System)
* **次数限制：** 每局比赛每位玩家固定拥有 **3次** 技能使用机会。
* **充能逻辑：**
    * **时间充能：** 自动随时间增长，充满需 20 秒。
    * **互动加成：** 每成功击球一次，充能进度即时增加 15%（约击球 6-7 次可满一次）。
* **视觉反馈：** 触发技能时产生 **0.8-1.2s 的慢动作定格动画**，并显示角色专属立绘（Cut-in）。

### 2. 角色库与技能数值
| 角色 | 梗来源 | 技能名称 | 逻辑效果 |
| :--- | :--- | :--- | :--- |
| **科比** | 曼巴精神 | **直升机扣杀** | 瞬间瞬移至高空，将球以 $V_{max}$ 垂直向下击出。 |
| **蔡徐坤** | 只因文化 | **只因之舞** | 击球路径变为非线性（如 S 型或瞬停），迷惑对手。 |
| **奶龙** | 软萌抽象 | **Duang!** | 身体及击球体积瞬间膨胀 3 倍，极大增加接球容错率。 |

---

## 四、 技术实现方案
### 1. 物理引擎与算法
* **碰撞检测：** 区分 `Body_Collider` 与 `Racket_Collider`。仅拍子触球计算主动击球向量，身体触球仅作随机反弹。
* **飞行公式：**
    * 应用 **线性阻力 (Linear Damping)** 模拟羽毛球由快到慢的真实坠落感。
    * 重力缩放 $GravityScale = 1.2$，线性阻力 $Damping = 0.8$。

### 2. 联机架构 (Networking)
* **方案：** 基于 **WebSocket** 的状态同步 (State Synchronization)。
* **判定权：** **服务器唯一判定**。客户端仅发送输入指令，服务器计算球的轨迹与得分逻辑，并将结果广播给双方。
* **后端语言：** Go。

---

## 五、 美术与音效需求
* **视角：** 固定全场横版视角，模拟经典《Stickman Badminton》。
* **背景：** 默认羽毛球馆，支持动态更换为“篮球场”或“异世界”背景图。
* **音效梗：**
    * 击球音效：清脆的球拍碰撞声。
    * 技能音效：角色代表性语音（如 "Music!", "Man!"）。
* **结算画面：** 极简设计，胜者播放庆祝动画 (Win_Loop)，败者播放沮丧动画 (Lose_Loop)。

## 六、 开发进度规划 (8周)
* **W1-W2 (原型期)：** Cocos 场景搭建，完成单机物理碰撞及 WASD 操作逻辑。
* **W3-W5 (联机期)：** 攻克 WebSocket 同步难点，实现双人同屏对战。
* **W6-W7 (内容期)：** 接入 3 个梗角色、技能系统、UI 界面及音效。
* **W8 (测试期)：** 修复同步延迟导致的 Bug，完善结算界面，准备提交文档。
