# 02 Main Menu Spec

## 一、页面目标

主页面只提供最小入口，让玩家能进入双人联机流程。

## 二、首版 UI

```text
┌──────────────────────────────┐
│                              │
│        抽象羽球大乱斗          │
│     Meme Badminton           │
│                              │
│        [ 双人联机 ]           │
│                              │
└──────────────────────────────┘
```

## 三、交互

### 点击“双人联机”

行为：

1. 切换到 `ONLINE_ROOM`。
2. 创建房间或加入匹配队列。

MVP 可以先不接真实服务器，使用本地模拟：

- 点击后直接进入房间等待。
- 开发调试时可以用按钮模拟“第二名玩家加入”。

## 四、暂缓按钮

以下按钮首版不做：

- 单人模式。
- 设置。
- 退出游戏。
- 角色图鉴。

如果 UI 需要占位，可以隐藏，不做不可用按钮。

## 五、验收标准

- 打开游戏后默认显示主页面。
- 页面上能看到游戏标题和“双人联机”按钮。
- 点击“双人联机”后进入房间/等待页面。
